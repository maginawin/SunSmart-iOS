# Site Trigger Zone 选中前后标题间距修复

## 问题与原因

非空 Item 的表头使用自动高度：未选中时主要由 24 pt 标题行与 8 pt 底部间距决定；选中后加入 44 pt 按钮，表头随之增高。宽度小于 300 pt 时还切换为纵向布局，使名称至下方卡片的距离进一步变化。No Data 表头始终为 40 pt，名称与按钮使用固定顶部约束。

## 修改

- 所有 Item 表头固定为 40 pt，与 No Data 一致；卡片内部仍保持内容自适应高度。
- 非空表头名称使用与 No Data 相同的字体适配、`SCRXFrom(8)` 左边距和 `SCRYFrom(15)` 顶部位置。
- 按钮组独立于标题行布局，复用 No Data 的顶部 `SCRYFrom(8)`、右边距 `SCRXFrom(9)`、按钮宽 `SCRXFrom(44)`、高 `Int(SCRYFrom(28))`、水平间距 `SCRXFrom(8)`。
- 选中只控制操作按钮的显示，不再撑高表头或将按钮换到第二行；长名称单行截断。
- 保留同步图标、View only、权限规则与原 No Data 实现，不修改共享 Group/Space 表头。
